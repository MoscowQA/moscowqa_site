# Inter для сайта

Шрифт, которым набран сайт. Раньше он приезжал с `fonts.googleapis.com`,
теперь лежит здесь:

- `inter-{подмножество}.woff2` — сами файлы;
- `../../css/fonts.css` — `@font-face` на них, его подключает
  `templates/base.html`.

## Почему перенесли

Ссылка на Google стоила похода на чужой CDN (два `preconnect`, DNS, TLS),
лишнего запроса за CSS **перед** запросом за самим шрифтом — и зависимости
от сервиса, который в России открывается не у всех: там, где он не
открылся, сайт показывался системным шрифтом. Со своего домена шрифт едет
по уже открытому соединению, и `<link rel="preload">` в `base.html`
запускает его загрузку сразу, не дожидаясь разбора CSS.

## Что здесь лежит

Шрифт вариативный по оси `wght`, поэтому все начертания сайта (400–800) —
это один файл на подмножество, а не пять. Подмножества и `unicode-range`
достались от Google как есть, так что браузер качает только то, что
встретилось на странице: русской странице нужны `cyrillic` (~18 КБ) и
`latin` (~47 КБ), остальные файлы просто лежат.

Лицензия — SIL Open Font License 1.1, полный текст в `OFL.txt`.

## Обновить

```bash
make fonts              # скачать заново и пересобрать fonts.css
make fonts ARGS=--dry-run
```

`static/css/fonts.css` собирается этим же прогоном — руками его не правим,
правки перетрёт следующий `make fonts`.

Если у Google поменяется набор подмножеств, рядом появятся новые файлы, а
неиспользуемые старые останутся — их надо удалить руками. И проверить
`rel="preload"` в `templates/base.html`: там поимённо перечислены
`inter-cyrillic.woff2` и `inter-latin.woff2`.

Отдельно от этой папки живёт `assets/fonts/Inter.ttf` — тот же шрифт, но
для `og_images.py`: Pillow рисует им обложки событий на сборке. Он в
`dist/` не попадает, обновляется своей командой (см.
`assets/fonts/README.md`).
